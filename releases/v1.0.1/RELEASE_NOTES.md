# ZotTagClear v1.0.1

Remove automatic tags or all tags from selected Zotero items or an entire library, with an option to restore the last cleanup.

## Features

- Clear Tags toolbar button with embedded icons.
- Tools submenu and selected-item context menu actions.
- Automatic-only and all-tag cleanup modes.
- Confirmation showing affected item and tag-assignment counts.
- Last-cleanup restore that preserves later tag additions.
- Option to prevent automatic tags on future imports using Zotero's native preference.

## Install

Download **ZotTagClear_v1.0.1.xpi**, open **Tools → Plugins** in Zotero, and drag the XPI onto the Plugins window. Restart if prompted.

The add-on manifest targets **Zotero 10.0.x**. Install newer XPI versions manually.

Library-wide actions include items outside the selected collection. Automatic-only cleanup removes tags Zotero marks automatic. A new cleanup that removes tags replaces the previous restore copy.
